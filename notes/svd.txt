Every linear map turns a circle into an ellipse; SVD tells you which perpendicular directions of the circle become the ellipse's axes, and how long those axes are.



Every matrix, however messy it looks, is secretly simple. If you choose the right set of perpendicular directions on the input side and the 
right set on the output side, the matrix just sends each input direction to its partner on the output side, stretching it by some amount. 
Nothing mixes; each direction travels alone.
